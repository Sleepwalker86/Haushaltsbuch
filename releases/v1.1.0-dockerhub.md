# Finanzapp v1.1.0 - Docker Hub Release

## 🎉 Neue Features

### Umstrukturierung der Datenverzeichnisse
- Alle Daten werden jetzt unter `/data` organisiert
  - `data/invoices/` - Belege zu Buchungen
  - `data/paperless/` - Bilder für Paperless-Upload
  - `data/log/` - Log-Dateien

### Umfassendes Logging-System
- Zentrales Logging mit automatischer Rotation (30 Tage)
- Log-Level konfigurierbar über `LOG_LEVEL`
- Download-Funktion für Log-Dateien in den Einstellungen

### Verbesserte Import-Feedback
- Detaillierte Statistiken beim CSV-Import
- Anzeige erfolgreich importierter und fehlerhafter Datensätze

## 🔧 Verbesserungen

- Optimierte Docker Volumes (ein `data`-Volume für alle Daten)
- Verbesserte Fehlerbehandlung und Logging
- Konsistentere Datenbank-Migrationen

## 🚀 Upgrade

```bash
docker compose pull
docker compose up -d
```
